# NodeSweep design system

A calm, compact operations dashboard: warm white surfaces, forest green actions, sage summary panels.

- Primary #246b57; text #243c35; background #f4f6f3; borders #e0e6df.
- System sans-serif, 12–14 px data, 21–26 px headings. No remote fonts or analytics.
- 8 px spacing rhythm; 14 px card corners; bordered surfaces, minimal shadows.
- Sidebar navigation, responsive cards, explicit empty/loading/error states.
- Treemap area represents allocated bytes; color only separates items, never promises safety.
- Destructive actions require a concrete preview and checked confirmation.
- Keyboard focus visible; button-based treemap, equivalent table navigation; mobile single-column layout.
