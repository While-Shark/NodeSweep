# NodeSweep 路线

## v0.1 Alpha — 当前

- [x] 单机 / Hub / Agent，Linux amd64 和 arm64
- [x] 独立节点凭证、主动上报、节点撤销
- [x] 运行指标、容量和 inode
- [x] 按需扫描、可下钻树图和列表
- [x] 自定义清理规则，按方案分组
- [x] 常见宝塔/1Panel/Nginx 目录预设

- [ ] 日志轮转配置检查；journal 原生 vacuum，Docker 原生轮转配置

- [ ] 批量节点分配与执行
- [ ] Agent 配置向导、一键安装、升级与更细粒度权限
- [ ] 英文 UI、键盘导航完善
