# NodeSweep 路线

## v0.1 Alpha — 当前

- [x] 单机 / Hub / Agent，Linux amd64 和 arm64
- [x] 独立节点凭证、主动上报、节点撤销
- [x] 运行指标、容量和 inode
- [x] 按需扫描、可下钻树图和列表
- [x] 自定义清理规则，按方案分组
- [x] 常见宝塔/1Panel/Nginx 目录预设
- [x] 短期预览、身份复核、归档删除、任务记录
- [x] 自动测试、构建、systemd 示例、开源文档

## v0.2 — 清理适配与易用性

- [x] 读取 1pctl 静态安装位置、宝塔 Nginx 静态站点日志（自定义宝塔目录支持 panelRoots）
- [x] Lumberjack 时间戳归档适配、日期校验与占用保护测试
- [ ] 更多日志轮转命名与各面板版本的实机适配
- [x] 有界只读日志轮转检查、受管理目录保护与 journal vacuum／Docker 轮转操作指南（原生维护由服务器管理员执行）
- [x] 方案 JSON 导入导出（事务保存、重复跳过、按方案导出）
- [x] 节点分组、批量扫描与预览、停止后续提交
- [x] 批量节点清理执行（逐台新预览与确认，最多 20 台／同时 2 台，不自动重试）
- [x] 校验下载、一键安装、保留配置升级与二进制回滚
- [x] 规则试运行与结构化清理报告
- [x] Agent 配置向导、本地只读部署检查（-check）
- [x] 更细粒度权限（只读／操作员／管理员，服务端校验）
- [x] 英语、日语、韩语、繁体中文 UI，语言偏好与本地化日期/数字
- [x] 键盘导航完善（弹窗焦点、Esc、恢复、inert 背景、正文跳转及树图标签）

## v0.3 — 持续运维

- [x] 磁盘/inode 阈值、离线与恢复告警、通用 HTTPS Webhook
- [x] 清理失败告警（独立开关、持久化去重、脱敏 Webhook）
- [x] 默认关闭的定时方案、Slack／Discord 格式与 HTTPS Relay 邮件转发指南（不内置 SMTP）
- [x] 聚合后的历史指标曲线（逐节点 CPU／内存／磁盘／inode，24 小时及七天，有界保留）
- [x] 单机/Agent 扫描取消、进度与部分结果
- [x] 显示时间的历史扫描复用（沿用有界保留，不用于授权清理）
- [x] 扫描条目、深度、时间、输出及节流预算
- [x] 节点指标采样资源预算（协作式一秒、128 个文件系统探测、32 KiB 载荷）
- [x] 多管理员、角色权限和独立审计事件（1000 条／30 天，变更前持久化）

## 发布前需要真实 VPS 验证

- [ ] 1Panel 默认目录与自定义目录
